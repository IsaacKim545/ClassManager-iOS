# 담임노트 (ClassManager for iOS)

교사를 위한 학급 관리 앱 **담임노트**의 공식 랜딩 페이지와 App Store 제출
자료입니다.

## 공개 페이지

| 페이지 | 주소 |
| --- | --- |
| 소개 (랜딩) | <https://isaackim545.github.io/ClassManager-iOS/> |
| 개인정보 처리방침 | <https://isaackim545.github.io/ClassManager-iOS/privacy.html> |
| 고객 지원 | <https://isaackim545.github.io/ClassManager-iOS/support.html> |

## 구성

```
.
├── index.html      랜딩 페이지
├── privacy.html    개인정보 처리방침 (App Store 필수 URL)
├── support.html    고객 지원 (App Store 필수 URL)
├── styles.css      전체 스타일
├── script.js       모바일 메뉴 · 스크롤 등장 효과
└── app-store/      App Store Connect 제출 자료
    ├── README.md
    ├── app-store-connect-metadata.md
    ├── app-privacy-details.md
    ├── review-notes.md
    └── submission-checklist.md
```

외부 이미지나 폰트, CDN을 사용하지 않는 정적 페이지입니다. 저장소를 내려받아
`index.html`을 바로 열어도 동일하게 동작합니다.
