# App Privacy (개인정보 라벨) 답변 — 담임노트

App Store Connect의 **앱 개인정보(App Privacy)** 설문에 입력할 값입니다. 라벨과
실제 앱 동작, 개인정보 처리방침의 내용이 서로 어긋나면 심사에서 반려되므로 아래
기준을 그대로 사용하세요.

## 결론 요약

| 구분 | 답변 |
| --- | --- |
| 이 앱이 데이터를 수집합니까? | **예** — 단, 광고 SDK가 수집하는 항목에 한함 |
| 사용자 추적에 사용되는 데이터가 있습니까? | **예** — 광고 식별자 (ATT 동의 시) |
| 사용자에게 연결되는 데이터 | 없음 |

## 1. 수집하는 데이터

### 식별자 → 기기 ID (Device ID)

| 항목 | 답변 |
| --- | --- |
| 수집 주체 | Google AdMob SDK |
| 사용 목적 | 서드파티 광고 |
| 사용자 신원에 연결됨 | 아니요 |
| **추적에 사용됨** | **예** |

### 사용 데이터 → 광고 데이터 (Advertising Data)

| 항목 | 답변 |
| --- | --- |
| 수집 주체 | Google AdMob SDK |
| 사용 목적 | 서드파티 광고 |
| 사용자 신원에 연결됨 | 아니요 |
| **추적에 사용됨** | **예** |

### 진단 → 충돌 데이터 / 성능 데이터

광고 SDK가 자체 진단 정보를 수집할 수 있습니다. Google AdMob 문서 기준으로
**진단(Diagnostics) → 기타 진단 데이터**를 "앱 기능", "사용자 신원에 연결되지
않음", "추적에 사용되지 않음"으로 함께 신고하는 것이 안전합니다.

## 2. 수집하지 않는 데이터 — "아니요"로 답할 항목

| 카테고리 | 사유 |
| --- | --- |
| 연락처 정보 (이름, 이메일, 전화번호, 주소) | 회원가입·로그인 자체가 없음 |
| 건강 및 피트니스 | 해당 없음 |
| 금융 정보 | 앱 내 구입 없음 |
| 위치 (정확한 위치) | 위치 권한을 요청하지 않음 |
| 민감한 정보 | 해당 없음 |
| 연락처 목록 | 접근하지 않음 |
| 사용자 콘텐츠 (사진, 오디오, 고객 지원 내용 등) | 학급·학생·상담·기록 자료는 **기기 밖으로 전송되지 않음** |
| 검색 기록 / 브라우징 기록 | 해당 없음 |
| 구입 내역 | 해당 없음 |

> **핵심 포인트:** 교사가 입력한 학생·상담·기록 자료는 기기 내 SQLite에만
> 저장되고 어떤 서버로도 전송되지 않으므로 "수집"에 해당하지 않습니다. 이
> 근거를 심사 메모에도 동일하게 기재했습니다.

## 3. 추적(Tracking)과 ATT

- 앱은 `expo-tracking-transparency`로 **App Tracking Transparency 안내를 먼저
  표시**한 뒤 광고 식별자를 사용합니다.
- `app.json`의 `NSUserTrackingUsageDescription`:
  `"이 식별자는 더 관련성 있는 광고를 제공하는 데에만 사용됩니다."`
- 사용자가 추적을 **허용하지 않아도 앱의 모든 기능을 제한 없이 사용할 수
  있습니다.** (허용을 강요하면 심사 반려 사유가 됩니다.)
- Android 권한 `com.google.android.gms.permission.AD_ID`는 iOS 심사와 무관합니다.

## 4. 계정 삭제 요구사항

Apple은 **계정 생성 기능이 있는 앱**에 계정 삭제 경로를 요구합니다. 담임노트는
계정 개념이 없으므로 해당하지 않으며, 대신 설정 화면의 **전체 초기화**와 **앱
삭제**로 모든 데이터를 즉시 제거할 수 있음을 심사 메모에 명시했습니다.

## 5. 개인정보 처리방침과의 일치 여부

| 라벨 항목 | 처리방침 대응 조항 |
| --- | --- |
| 기기 ID / 광고 데이터 수집, 추적 | 4항 「광고 및 기기 식별자」 |
| 학급 자료 미수집 | 1항 「기본 원칙 — 기기 내 저장」 |
| 계정 정보 미수집 | 2항 「회원가입과 계정」 |
| 데이터 삭제 방법 | 8항 「보유 기간과 삭제」 |
| 제3자 제공 범위 | 9항 「제3자 제공」 |
